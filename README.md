# 🚲 Bike Sharing Data Analytics Dashboard✨

Dashboard interaktif ini dibuat menggunakan **Python** dan **Streamlit** untuk menganalisis data penyewaan sepeda selama tahun 2011-2012. Proyek ini mencakup Analisis RFM (Recency, Frequency, Monetary) dan Clustering Manual untuk menemukan *insight* bisnis yang berharga.

## Setup Environment - Shell/Terminal
Jika Anda ingin menjalankan proyek ini secara lokal di komputer Anda, silakan ikuti langkah-langkah instalasi *environment* berikut:
```
mkdir bike_sharing_dashboard
cd bike_sharing_dashboard
pip install streamlit pandas matplotlib seaborn
pip install -r requirements.txt
```
## Run steamlit app
```
streamlit run dashboard.py
```
